## Overview

BDM puts the **paperwork next to the data**. Instead of a filing cabinet, staff see the student's documents from the student's record.

## Typical use cases

| Office | Documents |
|---|---|
| Admissions | Applications, transcripts, test scores, recommendations |
| Registrar | Graduation applications, grade change forms |
| Financial aid | Verification documents, appeals |
| HR | Contracts, employee forms |
| Accounts payable | Invoices, supporting documents |

## Keys to a good BDM setup

1. **Consistent indexing**: define which Banner fields index each document type.
2. **Retention rules**: decide how long each document type is kept.
3. **Security**: align document access with Banner roles.
4. **Capture workflow**: scanning, upload or automated import, with quality checks.
